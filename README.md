# ResumAI - Advanced AI Resume Builder SaaS

A premium, AI-powered resume builder designed to help you land your dream job. Built with the modern MERN stack and Google Gemini AI.

## ✨ Features
- **🚀 Modern UI/UX**: Stunning landing page, glassmorphism navbar, and smooth Framer Motion animations.
- **🤖 AI Assistant**: Generate and improve resume summaries and experience descriptions using Google Gemini AI.
- **⚡ Live Preview**: Real-time resume rendering as you type.
- **📊 Dashboard**: Manage multiple resumes easily.
- **🔐 SaaS Ready**: Integrated login/signup mockups and MongoDB backend.
- **🎨 Premium Templates**: Carefully crafted, ATS-friendly layouts.

## 🛠️ Technology Stack
- **Frontend**: React, Tailwind CSS, Framer Motion, Lucide React, Axios.
- **Backend**: Node.js, Express, MongoDB, Mongoose.
- **AI**: Google Generative AI (Gemini).

## 🚀 Getting Started

### 1. Prerequisites
- Node.js installed
- MongoDB installed or a MongoDB Atlas account
- Google Gemini API Key

### 2. Installation

#### Backend Setup
```bash
cd server
npm install
# Create a .env file and add your credentials (see .env.example)
npm start
```

#### Frontend Setup
```bash
cd client
npm install
npm run dev
```

### 3. Environment Variables
Create a `.env` file in the `server` directory:
```env
PORT=5000
MONGODB_URI=your_mongodb_uri
GEMINI_API_KEY=your_gemini_api_key
```
